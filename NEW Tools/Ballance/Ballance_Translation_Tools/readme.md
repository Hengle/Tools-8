## Ballance Translation Tools

Set of tools for translating Ballance PC game. (WORK IN PROGRESS)


### Export From Game Workflow:
1. Export translation files to CSV using Virtools 3.5 + BallanceVirtoolsHelper
2. Use this tool to: 
      - convert CSV to TXT for translation 
      - Copy files to OmegaT directory
3. Translate files in OmegaT and export them to "target" directory


### Import To Game Workflow:
1. Use this tool to:
   - replace chars in OmegaT "target" directory
   - convert TXT to CSV file
2. Import CSV files to game using Virtools 3.5 + BallanceVirtoolsHelper
